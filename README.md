# 오늘 할 일

`TodoWidget.exe`를 두 번 클릭하면 실행됩니다. Windows 기본 .NET Framework를 사용하며 추가 설치가 필요 없습니다.

- 아래 입력란에 할 일을 쓰고 Enter 또는 +를 누릅니다.
- 체크하면 완료 표시가 생깁니다. 다시 체크하면 완료를 해제합니다.
- 항목 오른쪽 연필 버튼으로 내용을 수정합니다. Enter로 저장하고 Esc로 취소합니다.
- 항목 오른쪽 휴지통 아이콘을 누르면 앱 내부 휴지통으로 이동합니다.
- 상단 휴지통에서 삭제한 항목을 확인하고 복원할 수 있습니다.
- 휴지통 화면 아래의 휴지통 비우기를 누른 뒤 확인 창에서 확인을 한 번 더 누르면 영구 삭제됩니다. 취소하거나 창을 닫으면 삭제되지 않습니다. 빈 휴지통에서는 버튼이 비활성화됩니다.
- 제목줄을 드래그하면 이동하고, 창의 네 가장자리와 네 모서리로 크기를 조절합니다. 크기 조절을 마치면 위치와 크기를 저장합니다.
- ☰ 메뉴에서 로그인 시 자동 실행과 항상 위에 표시를 켜거나 끕니다.
- ☰ → 화면 설정에서 불투명도(30-100%)와 모서리 둥글기(0-32px)를 조절합니다. 바로 미리 보이며 저장을 누르면 재실행 후에도 유지됩니다. 취소하면 이전 설정으로 돌아갑니다.
- 날짜는 연도·월·일·요일로 표시되고 실행 중에도 자동 갱신됩니다.
- ×는 앱을 종료합니다. 자동 실행을 켜 두면 다음 Windows 로그인 때 다시 열립니다.
- 작업 표시줄 알림 영역의 앱 아이콘을 두 번 클릭하면 위젯이 앞으로 나옵니다.

첫 실행 때 현재 사용자 계정의 로그인 자동 실행을 등록합니다. 실행 파일을 옮겼다면 새 위치에서 ☰ → 로그인 시 자동 실행을 껐다 켜 주세요. Windows 작업 관리자에서 시작 앱을 별도로 사용 안 함으로 설정했다면 사용으로 변경해야 합니다.

할 일은 이 PC의 `문서\TodoWidget Data\tasks.json`에 변경 즉시 저장됩니다. 이전 저장본은 `tasks.json.bak`입니다. 인터넷으로 전송하지 않습니다. 파일이 손상되면 원본을 덮어쓰지 않고 오류를 표시합니다.

앱을 제거하려면 먼저 ☰에서 자동 실행을 끄고 종료한 후 앱 폴더를 삭제하세요. 저장한 목록은 별도로 유지됩니다.

개발 소스는 `source`에 있습니다. Windows PowerShell에서 `source/build.ps1`을 실행하면 실행 파일을 다시 만듭니다. `TodoWidget.exe --self-test <빈 테스트 폴더 경로>`로 저장·완료·휴지통·복원 검사를 실행할 수 있습니다.

저장 위치는 문서 폴더의 TodoWidget Data입니다. 설정 메뉴의 저장 폴더 열기로 확인할 수 있습니다. 이전 AppData 목록은 새 저장 파일이 없을 때만 자동 이관합니다.
